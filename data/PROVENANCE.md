# Provenance of the sample data

Every file in this folder is **SYNTHETIC – generated by `tools/gen_samples.cpp`, not from a real ANSYS run**
(and not exported from a real CAD tool). Nothing here comes from a third party.

Regenerate everything (the output is deterministic, byte for byte):

```
cmake --build build --target gen_samples      # or: g++ -std=c++17 -O2 tools/gen_samples.cpp -o gen_samples
./gen_samples data                            # writes into ./data (default directory name is "data")
```

License for all files and the generator: own work, released as CC0 / MIT (use freely).

| File | What it is | Units | Schema |
|---|---|---|---|
| `cube.stl` | Cube with 10 mm edges, corner at the origin, 12 triangles, outward normals. | ASCII STL carries no units; **mm assumed** (so 10 x 10 x 10 mm, volume 1000 mm^3). | ASCII STL, one `solid cube_10mm`. |
| `heatsink.stl` | Finned heat sink: 48 x 30 mm base plate (3 mm thick) with 12 fins (1.5 mm thick, 17 mm tall); overall 48 x 30 x 20 mm. 204 triangles, closed surface, outward normals (checked by the generator and by `tests/test_parsers.cpp`: volume 13500 mm^3). | **mm assumed** (same reason). | ASCII STL, `solid heatsink_12_fins`. Profile extruded along +y, caps triangulated by ear clipping. |
| `synthetic_plate.csv` | Made-up nodal temperatures on a 21 x 21 x 2 node grid over a 0.2 m x 0.1 m x 0.01 m plate (882 nodes, ids 1..882). Field: `T = 40 + 140*exp(-r^2 / (2*0.035^2)) - 30*x/0.2 - 4*z/0.01` degC, with r the distance from a hot spot at (x, y) = (0.06 m, 0.05 m). Range about 6.0 to 171.0 degC. It only imitates the *shape* of an ANSYS nodal export. | x, y, z in **metres**; temperature in **degrees Celsius**. 6 significant digits. | `node_id,x_m,y_m,z_m,temperature_C` (see `docs/FORMATS.md`). |

## `bad/` – deliberately broken files for the error-handling demo

Each one must be rejected with a readable message (line numbers are 1-based; 0 = whole file).

| File | Defect | Expected error |
|---|---|---|
| `bad/empty.csv` | 0 bytes | line 0: "File is empty (0 bytes)..." |
| `bad/bad_header.csv` | header is `id,x,y,z,T` | line 1: "header column 1 is 'id', expected 'node_id'" |
| `bad/nan_value.csv` | temperature `nan` in the third data row | line 4: "column 5 (temperature_C) value 'nan' is not finite" |
| `bad/missing_endsolid.stl` | valid triangle, but no `endsolid` line | line 8: "end of file reached without 'endsolid'" |

Generated by the same command as above (`gen_samples` writes `<dir>/bad/*`).
